# DragLauncher v1.0.0

Первый релиз открытого лаунчера Minecraft DragLauncher с модульной архитектурой инстансов, встроенным каталогом модификаций Modrinth и поддержкой сторонних систем авторизации со скинами.

---

## Какой файл скачивать (Выбор версии)

В релизе представлены два варианта сборки программы. Выберите подходящий в зависимости от ваших задач:

### 1. DragLauncher Setup 1.0.0.exe (Установщик Windows — рекомендуется)
- Для кого: для большинства пользователей, которым нужна стандартная установка на ПК.
- Выбор папки установки: мастер установки позволяет указать любой локальный диск и произвольный каталог (например, `D:\Games\DragLauncher` или `C:\Program Files\DragLauncher`).
- Автоматические ярлыки: создает ярлыки с иконкой высокого разрешения на Рабочем столе и в главном меню Пуск.
- Системная интеграция: регистрируется в системе Windows с возможностью корректного и полного удаления через меню Параметры -> Установленные приложения.

### 2. DragLauncher 1.0.0.exe (Портативная версия / Portable)
- Для кого: для пользователей, предпочитающих запуск программ без инсталляции.
- Без установки: единый автономный файл, который не требует прав администратора и не оставляет записей в реестре операционной системы.
- Мобильность: можно запускать прямо из папки загрузок, хранить на съемных USB-накопителях или внешних дисках.

## Настройка папки для загрузки файлов и версий игры

Вне зависимости от выбранного варианта запуска лаунчер позволяет хранить тяжелые игровые файлы отдельно от операционной системы:
- В левом меню лаунчера откройте раздел Настройки.
- В поле Папка загрузки и данных игры нажмите кнопку Обзор и укажите любой каталог на любом диске (например, `D:\MinecraftData`).
- Все скачиваемые официальные версии Minecraft, клиентские библиотеки, текстуры, звуки и игровые инстансы будут загружаться и храниться в указанной директории.
- Кнопка По умолчанию позволяет вернуть стандартный системный путь (`%APPDATA%\draglauncher`).

## Основные возможности лаунчера

- Изолированные инстансы: каждый игровой профиль полностью изолирован в собственной папке .minecraft со своими модами, настройками и сохранениями.
- Каталог Modrinth: встроенный поиск и установка модов, шейдеров и ресурс-паков в один клик без перехода на сторонние сайты.
- Система профилей и скинов: поддержка учетных записей TLauncher с загрузкой персональных скинов и плащей, поддержка Ely.by (через authlib-injector) и офлайн-профилей.
- Оптимизированный запуск Java: автоматическое обнаружение установленных версий Java (8, 17, 21, 26) и автоматическое применение параметров стека (-Xss1M, -XX:StackShadowPages=32) для стабильной работы современных версий игры.
- Встроенный мониторинг: журнал логов процесса Minecraft в реальном времени с подсветкой ошибок и возможностью экстренной остановки.

## Системные требования

- Операционная система: Windows 10 или Windows 11 (64-bit).
- Среда выполнения Java: Java 8 (для версий Minecraft 1.16.5 и старее) / Java 17, 21 или новее (для современных версий).
- Подключение к сети Интернет: требуется для первой загрузки выбранных версий игры, ассетов и модификаций.
