# DragLauncher

Современный и открытый Minecraft-лаунчер, объединяющий возможности **Prism Launcher** (изолированные инстансы, встроенный поиск и установка модов, шейдеров и ресурс-паков через Modrinth API) и гибкую систему аккаунтов со скинами (**TLauncher**, **Ely.by**, **Offline**, **Microsoft**).

Интерфейс спроектирован в минималистичной тёмной эстетике **NovaCode** на стеке Electron, React 19, TypeScript и Tailwind CSS.

---

## Основные возможности

### Изолированные инстансы (в стиле Prism Launcher)
- Полная изоляция профилей (`.minecraft` в каждой отдельной директории инстанса).
- Автоматическое скачивание официальных версий и снапшотов напрямую с серверов Mojang (Piston Meta).
- Поддержка модифицированных загрузчиков: Fabric, Forge, NeoForge, Quilt.
- Автоматическое обнаружение установленных версий Java (Java 8, 17, 21, 26) и умный подбор под версию игры.
- Встроенная консоль логов в реальном времени с подсветкой ошибок и возможностью экстренной остановки.

### Каталог Modrinth: Моды, Шейдеры и Ресурс-паки в 1 клик
- Встроенный удобный менеджер контента инстанса с отдельными вкладками:
  - **Моды**: скачивание прямо в `.minecraft/mods` с авто-фильтрацией по лоадеру и версии.
  - **Ресурс-паки**: поиск и установка текстур прямо в `.minecraft/resourcepacks`.
  - **Шейдеры**: поиск и установка шейдер-паков прямо в `.minecraft/shaderpacks`.
- Включение / отключение модов и паков в один клик без удаления (`.disabled`).
- Быстрое открытие целевой папки в проводнике.

### Система аккаунтов и скинов
- Авторизация через `tlauncher.org` со скинами и плащами.
- Поддержка скинов `Ely.by` через динамическую интеграцию `authlib-injector`.
- Офлайн-профили (генерация корректного RFC v3 UUID).
- Возможность быстрого переключения активного профиля прямо из верхней панели.

## Сборка из исходного кода

### Требования
- **Node.js** (v18+)
- **npm** (v9+)
- Установленная **Java** (Java 8, 17, 21 или новее) для запуска самой игры

### Установка зависимостей
```bash
git clone https://github.com/Daigren/DragLauncher.git
cd DragLauncher
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```

### Сборка исполняемого файла (.exe)
```bash
npm run dist
```
Готовый переносимый исполняемый файл будет сгенерирован в папке `release/`.

## Безопасность и чистота кода

- **Открытый исходный код**: Репозиторий содержит исключительно читаемый TypeScript/React исходный код без обфускации или скрытых процессов.
- **Безопасность учетных записей**: Пароли и токены передаются напрямую на соответствующие официальные эндпоинты авторизации и хранятся локально в пользовательской директории операционной системы.
- **Никаких пиратских ассетов**: Лаунчер не содержит и не распространяет проприетарные файлы игры. Все библиотеки, ассеты и клиентские `.jar` загружаются напрямую с официальных серверов Mojang при первом запуске инстанса.
